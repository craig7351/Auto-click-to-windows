# AfkKeeper — 視窗定時送鍵工具

> 📌 **專案來源**：本專案衍生自 [craig7351/Auto-click-to-windows](https://github.com/craig7351/Auto-click-to-windows) 開源專案。在此基礎上進行客製化增強與功能擴充（包含防誤觸半透明遮罩、右上角浮動延長按鈕、每日定時排程、ESC 鍵支援、精準行程名稱解析與專屬圖示等）。

對**指定的已開啟視窗**，每隔自訂時間送出一個按鍵（預設上箭頭 Up）。

## 特色

- **不干擾你的操作**：用 `GetLastInputInfo` 偵測閒置，只在你手停下來的空檔才送鍵，送完立刻把焦點還給你原本的視窗（約 0.2 秒）
- **遊戲收得到**：用 `SendInput` + scan code，而非 `PostMessage`（Roblox 等用 DirectInput 的遊戲可以收到）
- **防誤觸半透明遮罩**：掛機時自動在目標視窗覆蓋半透明遮罩，防止滑鼠誤操作，遮罩上提供「暫時關閉」與「每日定時」雙按鈕一鍵解鎖
- **暫時關閉（休息/手動操作）**：提供暫停 1 分鐘（預設）、15/30/60 分鐘或自訂時間解鎖視窗，時間到自動恢復掛機
- **即將到期右上角浮動延長**：當關閉時間小於 1 分鐘時，在目標視窗右上角浮現「⏳ ＋延長 1 分鐘」按鈕，點選可再延長 1 分鐘（僅在焦點於目標視窗時顯示，切換到其他視窗時自動隱藏不干涉）
- **每日定時自動排程**：自訂每日自動掛機時段（例如 01:00～07:00），時段外自動解鎖視窗供正常使用，支援跨夜設定
- **📊 每日暫停統計與視覺化 HTML 報表**：
  - 完整記錄三種暫停情境：遮罩暫時解鎖/延長、手動停止掛機、每日定時離峰待命
  - 一鍵生成現代深色科技風 HTML 報表（支援每日堆疊長條圖、類型圓環圖、KPI 指標卡片、每日彙總與明細清單）
  - 支援跨午夜時間精準分割統計、即時關鍵字搜尋、篩選今天/7天/14天/30天/全部歷史、一鍵匯出 CSV 與列印
- **防規律偵測**：間隔支援 ± 隨機秒數抖動
- **記憶上次設定**：自動儲存視窗、秒數、排程等設定，下次開啟免重設
- **單一 exe，無需安裝**：使用 Windows 內建 .NET Framework 4.x，雙擊即用
- 可縮到**系統匣**背景執行

## 下載

直接下載 [AfkKeeper.exe](AfkKeeper.exe)，雙擊執行，無需安裝任何環境。

## 使用方式

1. 開啟目標程式（例如 Roblox）
2. 執行 AfkKeeper，從下拉選單選擇目標視窗（自動嘗試選中 Roblox）
3. 設定間隔秒數（預設 780 秒 = 13 分）、按鍵、隨機抖動
4. 勾選「只在我閒置時送鍵」（推薦）與「半透明遮罩」
5. 按「▶ 開始」，目標視窗將覆蓋半透明遮罩防止誤觸，按下遮罩上的「暫時關閉」或「每日定時」即可解鎖正常操作視窗

## 重新編譯

```bat
build.bat
```

使用 Windows 內建 `csc.exe`，不需安裝 .NET SDK。

## 注意

本工具為純外部輸入模擬（不注入 DLL、不讀寫遊戲記憶體），但仍可能違反特定遊戲服務條款中關於掛機的規定。請自行評估風險，建議僅供個人使用。
